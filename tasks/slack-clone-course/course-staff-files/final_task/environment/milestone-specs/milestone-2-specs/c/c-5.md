## Rules

### C5. Profiles

C5.1 **Read a profile.** `GET /api/users/{id}` returns `200` and `{user}` with every `UserObj`
field (`id`, `username`, `display_name`, `timezone`, `avatar_url`, `status_text`, `status_emoji`)
and no password field.

C5.2 **Edit your profile.** `PATCH /api/users/me` with any subset of `{display_name, timezone,
avatar_url, status_text, status_emoji}` saves exactly those fields and returns `200` and `{user}`.
Every node then shows the new values.

C5.3 **Validation.** `timezone` must be a known IANA zone (`zoneinfo.ZoneInfo(name)` succeeds;
install `tzdata`). Lengths: `display_name` 1 to 80 characters, `status_text` at most 140,
`status_emoji` at most 32, `avatar_url` at most 512. Every field is a string. Anything else returns
`400` and saves nothing from that request.

C5.4 **Broadcast.** After a profile update, every connected WebSocket client on every node,
whatever it is subscribed to, receives `{"type": "user.updated", "user": UserObj}` within 2
seconds. The frame has no `channel_id` and no `event_id`.

Every request must answer within 5 seconds.
