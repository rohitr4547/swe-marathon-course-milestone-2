## Rules

### C3. Slash commands

A body starting with `/` is a slash command. The commands are `/me`, `/shrug`, `/topic`,
`/invite @user`, `/archive` and `/unarchive`. A body starting with `//` is not a command.

C3.1 **/me.** `/me <text>` posts a normal message (`201`) whose `body` stays exactly
`"/me <text>"`. `/me` with no text (or only spaces) returns `400`.

C3.2 **/shrug.** `/shrug <text>` posts a normal message whose `body` is `<text>` followed by a space
and `¯\_(ツ)_/¯` (one backslash). `/shrug` alone posts just `¯\_(ツ)_/¯`.

C3.3 **Literal and unknown.** A body starting with `//` posts a normal message with the first `/`
removed (`//etc/hosts` → body `/etc/hosts`). Any other unknown command returns `400`.

C3.4 **/topic.** `/topic <text>` sets the channel topic and returns `201` with
`{message: null, channel}` (the updated ChannelObj). No message is stored.

C3.5 **/invite.** `/invite @<username>` adds that workspace member to the channel and returns
`201` with `{message: null, invited_user}` (their UserObj).

C3.6 **/archive and /unarchive.** Only the workspace owner may run them (others get `403`); each
returns `201` with `{message: null, channel}`. While archived, other posts return `423`, but
`/unarchive` works.

Every request must answer within 5 seconds.
